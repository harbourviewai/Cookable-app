# Marketing

Launch and content playbook. The plan is in `../knowledge/13-marketing-plan.md` — this folder holds the actual artifacts.

Suggested structure:

- `tiktok/` — script drafts, video ideas, posted log
- `linkedin/` — build-in-public post drafts
- `reddit/` — drafted posts per subreddit, with rules of each sub
- `press/` — pitch templates, contact list, sent log
- `influencer-list.md` — 50 micro-influencers to DM at launch
- `landing-page/` — copy and assets for cookable.app
- `launch-week.md` — the day-by-day launch playbook

The single most important thing per the marketing plan: **post on TikTok every day for 60 days**. Build the TikTok pipeline first.
