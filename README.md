# Cookable

> Cook anything. Waste nothing.

AI app that turns whatever's in your fridge into 3 recipes you can cook tonight, prioritizing ingredients about to expire.

## Repo layout

- `CLAUDE.md` — project context for Claude Code sessions
- `knowledge/` — full product spec, split into focused docs
- `plans/` — implementation plans
- `notes/` — build journal and decision log
- `marketing/` — launch and content playbook
- `assets/` — brand assets and screenshots
- `app/` — the Expo / React Native codebase (initialized on Day 1 of build)

## Quick start (in Claude Code)

```

/next-task
```

## Stack

React Native (Expo) + Supabase + Claude Sonnet 4.5 (Anthropic API) + RevenueCat + AdMob + PostHog.
