# Assets

Brand and store assets. Source files go here; exports get pulled into `app/assets/` once the codebase exists.

## Structure

- `brand/` — logo (wordmark + icon, all variants), color tokens, type specimens
- `screenshots/` — App Store + Play Store screenshots, all required sizes

## Designer deliverables expected (from brand doc)

- Wordmark (horizontal)
- App icon (1024×1024 master + all platform exports)
- App icon dark variant (Pine background)
- Stacked lockup (icon + wordmark)
- Single-color versions (white on dark, dark on white)

**Budget:** $300-500 on Dribbble or 99designs

See `../knowledge/12-brand-identity.md` for full brand system.
