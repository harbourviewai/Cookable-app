# Notes

Build journal, decision log, scratch notes. Markdown only.

Suggested files:

- `journal.md` — running log of build days, what shipped, what broke
- `decisions.md` — significant decisions with rationale (architecture, scope cuts, scope adds)
- `learnings.md` — things you learned the hard way that future-you should know
- `parking-lot.md` — ideas/features deliberately deferred (with date and reason)

Keep entries dated. Don't worry about polish — these are for you, not the public.
